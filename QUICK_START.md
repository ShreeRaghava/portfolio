## 🎯 YOUR TASK IN 3 STEPS

### STEP 1: Add Your Images (5-10 minutes)

**Create a folder:**
- In VS Code: Right-click in Explorer → New Folder → Name it `assets`

**Add your images to `assets` folder:**
- Your profile photo: `your-image-1.jpg`
- Gallery photos: `your-image-2.jpg`, `your-image-3.jpg`, `your-image-4.jpg`
- Project images: `project-1.jpg`, `project-2.jpg`, etc.
- Book cover: `book-cover.jpg`

**Don't have images yet?**
- Use https://unsplash.com (search: ocean, beach, water, technology)
- Download & save to `assets` folder
- Or create placeholder designs in Canva

---

### STEP 2: Customize Your Content (10 minutes)

**Open `index.html` in VS Code and replace:**

1. **Your Name:** Find `[Your Name]` → Replace with your name
2. **Professional Title:** Find `Creative AI Engineer` → Your title
3. **Email:** Find `your.email@gmail.com` → Your email
4. **Phone:** Find `+1 (234) 567-890` → Your phone
5. **Social Links:** Find `yourusername` → Your GitHub username
6. **About Text:** Find the paragraph in About section → Write your story
7. **Project Names & Descriptions:** Update with your real projects
8. **Book Title:** Update with your book details
9. **GitHub Repos:** Add your real repository names & links

**Quick Tip:** Use Ctrl+H (Find & Replace) to change multiple instances at once!

---

### STEP 3: Test & Deploy (5 minutes)

**Test Locally:**
1. Right-click `index.html`
2. Select "Open with" → Chrome/Firefox
3. Check everything looks good
4. Test on mobile (F12 → Device Toolbar)

**Deploy (Choose One):**

**Option A: GitHub Pages (FREE, PERMANENT)**
```bash
# In Terminal, navigate to your portfolio folder:
cd l:/Portfolio

# Initialize git
git init
git add .
git commit -m "My portfolio"

# Create GitHub repo at github.com/new
# Copy the commands and run them:
git remote add origin https://github.com/yourusername/portfolio.git
git branch -M main
git push -u origin main

# Your site: https://yourusername.github.io/portfolio
```

**Option B: Vercel (EASIEST)**
1. Go to vercel.com
2. Sign up with GitHub
3. Click "New Project"
4. Select your portfolio repository
5. Click Deploy
6. Your site is LIVE! ✨

**Option C: Netlify (ALSO EASY)**
1. Go to netlify.com
2. Drag & drop your Portfolio folder
3. Site is LIVE instantly!

## ❓ COMMON QUESTIONS

**Q: How do I change the colors?**
A: Open `styles.css`, find `:root` section (line 13), modify the color values

**Q: The images aren't showing?**
A: Make sure:
1. Images are in `assets` folder
2. Filenames match exactly (case-sensitive)
3. Image formats are JPG or PNG
4. Clear browser cache (Ctrl+Shift+Delete)

**Q: How do I make the contact form send emails?**
A: The form currently opens your email client. For automatic emails, use:
- Formspree.io (free)
- EmailJS.com (free)
- Or your email hosting provider's contact form

**Q: Can I add more sections?**
A: Yes! Duplicate any section in `index.html`, give it a new ID, and add to navigation

**Q: How do I make it mobile-friendly?**
A: It's already mobile-responsive! Test with F12 → Device Toolbar in browser

**Q: Can I use a custom domain?**
A: Yes! On GitHub Pages, Vercel, or Netlify settings, you can add a custom domain
