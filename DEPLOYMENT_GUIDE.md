## 🏆 OPTION 1: VERCEL (RECOMMENDED FOR SPEED)

**Fastest & Easiest! Takes 5 minutes.**

### Steps:

**1. Sign up:**
- Go to https://vercel.com
- Click "Sign Up"
- Choose "GitHub" → Authorize → Done

**2. Deploy:**
- Click "Add New Project"
- Click "Continue with GitHub"
- Select your portfolio repository (or upload folder)
- Click "Deploy"
- **DONE! Your site is LIVE!** ✨

**Your URL will be:** `https://portfolio-yourusername.vercel.app` (or custom domain)

### Pros:
✅ Takes 5 minutes  
✅ Very intuitive  
✅ Automatic updates  
✅ FREE custom domain  
✅ Perfect for portfolios

## 🌐 OPTION 2: GITHUB PAGES (RECOMMENDED FOR CONTROL)

**Best for GitHub integration and free custom domain.**

### Prerequisites:
- GitHub account (free at https://github.com)
- Git installed on your computer

### Steps:

**1. Create GitHub Repository:**
```
1. Go to https://github.com/new
2. Repository name: "portfolio"
3. Description: "My creative portfolio"
4. Choose "Public" (so it's visible)
5. Click "Create repository"
```

**2. Upload Files (Choose ONE method):**

**Method A: Using Git Terminal (Recommended)**

Open PowerShell and run:
```powershell
cd l:\Portfolio
git init
git add .
git commit -m "Initial portfolio commit"
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
git branch -M main
git push -u origin main
```

Replace `YOUR_USERNAME` with your actual GitHub username!

**Method B: Using GitHub Desktop (Easier)**
1. Download GitHub Desktop: https://desktop.github.com
2. Open it, sign in with GitHub
3. Click "Create New Repository"
4. Choose your portfolio folder
5. Name it "portfolio"
6. Click "Create Repository"
7. Click "Publish Repository"

**3. Enable GitHub Pages:**
```
1. Go to your repository on github.com
2. Click "Settings"
3. Click "Pages" (left sidebar)
4. Under "Source", select "main" branch
5. Click "Save"
6. Wait 1 minute...
7. Your site is LIVE at: https://YOUR_USERNAME.github.io/portfolio
```

### Pros:
✅ Free forever  
✅ Version control  
✅ Easy updates  
✅ Professional GitHub presence  
✅ Works perfectly with portfolios  

### Cons:
⚠ Takes 10 minutes
⚠ Requires Git knowledge
⚠ URL includes "github.io"

## 🔗 CUSTOM DOMAIN (OPTIONAL)

Want `yourname.com` instead of `github.io`?

### Using GitHub Pages:
1. Buy domain at: GoDaddy, Namecheap, Google Domains
2. Go to your repository → Settings → Pages
3. Under "Custom domain", enter: `yourname.com`
4. Update domain DNS settings (follow GitHub's instructions)

### Using Vercel:
1. In Vercel dashboard, click your project
2. Go to "Settings" → "Domains"
3. Add your custom domain
4. Follow DNS setup instructions

### Using Netlify:
1. In Netlify dashboard, click your site
2. Go to "Domain settings"
3. Click "Add custom domain"
4. Follow DNS setup

**Cost:** Usually $10-15/year for domain

## 🆘 TROUBLESHOOTING

**"My site is blank!"**
- Check files are uploaded correctly
- Make sure `index.html` exists
- Clear browser cache (Ctrl+Shift+Delete)
- Check browser console (F12) for errors

**"Images not showing!"**
- Check images are in `assets` folder
- Check filenames match exactly
- Verify image paths in HTML
- Try hard refresh (Ctrl+Shift+R)

**"Page still shows old content!"**
- Clear browser cache: Ctrl+Shift+Delete
- Use Incognito/Private window
- Wait 5-10 minutes for cache to clear
- Try different browser

**"Getting 404 error?"**
- Make sure `index.html` exists
- Check repository is public
- Re-deploy the site
- Check branch name is correct
