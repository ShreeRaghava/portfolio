## ❓ FAQ (Frequently Asked Questions)

**Q: How do I test it locally before deploying?**
A: Right-click `index.html` → "Open with" → Chrome/Firefox

**Q: Can I change the colors?**
A: Yes! Edit `:root` variables in `styles.css` (line 13)

**Q: How do I add more projects?**
A: Copy one project card and paste it again, then update the content

**Q: Images not showing?**
A: Make sure they're in `assets` folder with exact filenames

**Q: Can I use a custom domain?**
A: Yes! Buy domain at GoDaddy/Namecheap, update DNS settings

**Q: How often should I update it?**
A: Add new projects quarterly, update frequently on social media

**Q: Will it work on mobile?**
A: Yes! It's fully responsive and mobile-friendly

**Q: Is the contact form secure?**
A: It opens your email client. For automated emails, use Formspree
